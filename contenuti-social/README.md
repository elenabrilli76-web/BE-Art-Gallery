# Creazione contenuti social

Lo spazio di lavoro per reel, post, caroselli e storie di BE Art Gallery.

- **[`PROCESSO.md`](PROCESSO.md)** — il processo completo. Parti da qui.
- **[`BRIEF.md`](BRIEF.md)** — modello facoltativo, se preferisci scrivere la richiesta invece di dirla
- **`in-lavorazione/`** — il contenuto su cui stai lavorando adesso, uno per volta:
  - `foto/` le foto scelte, rinominate `01.jpg`, `02.jpg`, `03.jpg`…
  - `testi.md` caption, hashtag e note — le scrive Claude
  - `contenuto.json` le istruzioni per il comando — le scrive Claude
  - `pronti/` i file finiti, da passare sul telefono
- **`pubblicati/`** — archivio: una cartella per contenuto

## Il giro

```
1. foto in in-lavorazione/foto/     (tu)
2. dici cosa vuoi                   (tu → Claude)
3. py strumenti\crea.py             (tu)
4. scarichi da pronti/ e pubblichi  (tu)
```

Uguale per tutti e quattro i formati.
