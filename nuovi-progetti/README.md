# Nuovi progetti

Le proposte in valutazione — mostre, artisti, iniziative — prima che siano
decise, o decise ma senza ancora una collocazione definitiva. È lo spazio in
cui un progetto prende forma finché non **va in porto**: a quel punto si
sposta nei posti giusti (il calendario in `CLAUDE.md`, `testi-critici/`,
`laboratori/`, `servizi-per-l-arte/`) e qui ne resta solo la traccia, o si
toglie.

È successo così per «Siamo Donne, oltre la violenza c'è di più»: nato come
proposta, oggi è l'evento che contiene DONNE: Femminile Plurale.

## Come è organizzato

Una cartella per proposta in `progetti/nome-cognome/`, con dentro:

| File | Cosa contiene |
|---|---|
| `README.md` | di cosa si tratta, la formula decisa, cosa resta da fissare |
| `materiali/` | immagini, PDF della proposta: **solo sul PC** |

## Riservatezza

Il repository è pubblico. Nelle proposte non vanno indirizzi, telefoni,
email dell'artista, né valutazioni critiche sulla proposta: quelli restano
fuori da GitHub.
